# 🚀 Jornada de Aprendizagem em C e C++

Um repositório dedicado ao estudo da Linguagem C, C++ e aos fundamentos da Ciência da Computação, focado em gestão de memória, arquitetura de sistemas e algoritmos de baixo nível.

---

## 🎯 Objetivos

- [x] Dominar os conceitos fundamentais da linguagem C (sintaxe, controlo de fluxo, funções).
- [ ] Entender a fundo a gestão de memória (Ponteiros, Alocação Dinâmica, Stack vs. Heap).
- [ ] Implementar estruturas de dados clássicas do zero (Listas Encadeadas, Pilhas, Filas, Árvores).
- [ ] Transitar para C++ e explorar Programação Orientada a Objetos (POO) e a STL.
- [ ] Compreender como o código interage diretamente com o hardware e o sistema operativo.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagens:** C (C11/C17) | C++ (C++20)
- **Compilador:** GCC / G++ (MinGW-w64)
- **Editor/IDE:** Visual Studio Code
- **Ferramentas de Diagnóstico:** GDB (Debugger), Valgrind (Análise de Memória)
- **Controlo de Versão:** Git & GitHub

## 🗺️ Roteiro de Estudos (Roadmap)

## 💻 Como copilar e executar
# Entrar na pasta do exercício
```` bash
cd "Conceitos iniciais"
````
# Compilar com o GCC gerando o executável
```` bash
gcc main.c -o programa
````
```` bash
# Executar no Windows
.\programa.exe
````
```` bash
# Executar no Linux/macOS
./programa
````
